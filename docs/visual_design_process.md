# TMJ 內視鏡手術衛教視覺化專案紀錄

## 1. 專案目的

本專案將顳顎關節內視鏡手術相關簡報內容，轉換為適合病人衛教使用的視覺化圖像。設計目標不是取代醫療諮詢，而是協助病人理解：

- 為什麼需要術前評估
- 什麼情況可能考慮內視鏡
- 內視鏡主要能看到哪些區域
- 手術可能達成的目標
- 為什麼術後療效要以疼痛與功能為主追蹤

## 2. 衛教內容的共同邏輯

所有圖像沿用以下臨床溝通順序：

1. **先描述症狀與功能問題**：疼痛、卡住、張口受限、咀嚼或進食受影響。
2. **再整合臨床檢查與影像**：症狀不能只靠單一影像或單一檢查判斷。
3. **說明內視鏡的能力與限制**：主要觀察上關節腔，並非能看見整個關節與所有周邊組織。
4. **依術中病灶與組織品質調整處置**：沖洗、去沾黏、盤復位、固定或修補不是固定套餐。
5. **用病人真正感受到的功能追蹤效果**：疼痛、張口度、下顎偏移、進食與咀嚼耐受力。

## 3. 視覺系統

### 色彩

- 米白背景：降低醫療冷硬感，延續原簡報的留白風格。
- 深藍：標題、流程終點、主要結構與重要訊息。
- 棕色／陶土色：編號、手術器械、重點或警示。
- 灰藍與青綠：影像、關節腔、分區或補充資訊。
- 淡粉色：需另案討論或治療界線，避免使用鮮紅造成不必要恐慌。

### 圖像風格

- 解剖內容採寫實、教科書式醫學插圖。
- 不使用血腥、手術傷口或誇張疼痛表現。
- AI 生成圖不直接承載關鍵文字，以避免醫學標籤與中文字誤植。
- 文字與資訊層級使用 HTML/CSS 排版，確保內容可讀且可修改。
- 所有成品都加上「示意圖／實際評估依醫師判斷」類型的限制說明。

## 4. 版面架構

主衛教圖通常採「標題＋一句核心訊息＋中央或左側寫實圖像＋右側／下方資訊卡」結構：

- 上方：單一明確標題與病人能理解的副標。
- 中段：一張主要解剖或臨床情境圖。
- 資訊卡：每張卡只處理一個概念，避免把診斷、手術與術後追蹤混成一張圖。
- 下方：流程、限制或醫療使用提醒。

## 5. 交付與審閱標準

每張圖在交付前檢查：

- 是否正確對應原始投影片內容。
- 解剖構造是否符合顳顎關節的基本空間關係。
- 是否清楚區分示意圖與實際手術視野。
- 是否避免把影像所見寫成確定診斷。
- 是否避免宣稱手術必然成功或能消除所有關節聲音。
- 文字是否完整、無裁切、無重複且適合病人閱讀。
- PNG 與 HTML 是否都能正常開啟。

## 6. 醫療使用限制

本專案是病人衛教視覺素材，不是診斷工具、適應症判定工具，也不是手術操作指南。實際解剖、影像判讀、手術入口、術式與治療計畫，必須由合格醫療團隊依個別患者的症狀、理學檢查與影像判斷。正式對外使用前，應由口腔顎面外科、顳顎關節或相關專科醫師審閱。
