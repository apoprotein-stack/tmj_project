# TMJ Patient Education Visuals

顳顎關節（TMJ）衛教圖片專案，包含主題一「認識顳顎關節與常見問題」及主題二「微創顳顎關節內視鏡手術的原理與適應症」的視覺素材。

## 內容

- `assets/theme1/`：顳顎關節位置、關節盤正常與移位、張口運動、常見問題、症狀來源。
- `assets/theme2/`：微創內視鏡原理、適應症與病理狀態、入口位置與概念流程。
- `assets/theme2/archive_original/`：主題二早期版本，保留作為設計修訂紀錄。
- `assets/theme2/visual_guides/`：本次新增的手術目的、術前評估、適應情況與治療界線、內視鏡檢查範圍衛教圖，以及相關寫實醫學插圖素材。
- `source/`：原始衛教簡報。

## 專案紀錄與可重現文件

本專案採用「**寫實醫學素材＋可控 HTML/CSS 資訊版面**」的生圖架構。AI 主要負責生成無文字的教科書式解剖、臨床檢查與影像情境；標題、醫療用詞、流程、限制提醒與圖說則由 HTML/CSS 排版，以降低解剖標籤與中文字誤植的風險。完成後再將 HTML 的 `main` 容器輸出為 PNG，供簡報或衛教使用。

`docs/visual_design_process.md` 說明整體衛教邏輯、視覺系統、版面規則、審閱標準與醫療使用限制。`docs/visual_guides_log.md` 逐張記錄四張衛教圖的設計目標、資訊架構、生圖提示詞與修改歷程。`docs/reproduction_workflow.md` 說明檔案結構、提示詞撰寫原則、HTML 匯出方式、輸出檢查清單與正式臨床發布前的審閱流程。

### 衛教邏輯摘要

四張新增衛教圖依照病人理解順序排列：先說明手術想改善的疼痛與功能，再說明術前如何整合臨床檢查、MRI 與 CBCT／CT；接著界定何時可能考慮內視鏡，以及哪些情況需先排除或另案討論；最後說明內視鏡主要觀察上關節腔的哪些區域。共同原則是：影像不能脫離症狀單獨判讀，術式依術中病灶與組織品質調整，療效則以疼痛與功能追蹤為主。

### 生圖與修改原則

所有生成素材都要求無文字、無標籤、無血腥內容與無品牌標誌，並以顳顎關節寫實剖面作為解剖參考。經檢查後，文字資訊會放在可編輯版面中；若初版圖像過於抽象或解剖可信度不足，會改用教科書式剖面重新生成，而不是以抽象符號代替解剖圖。完整 prompt 與每次主要修改原因均記錄在 `docs/visual_guides_log.md`。

## 視覺標準

主題二採用「正常比例的外部解剖定位＋獨立的關節腔放大視窗」標準。放大視窗均明確標示 `ENLARGED — NOT TO SCALE` 或 `SCHEMATIC — NOT TO SCALE`，避免將衛教示意誤解為實際人體比例或手術操作圖。

## 醫療使用提醒

所有圖片皆為患者衛教示意圖，不能單獨作為診斷、適應症判定或手術操作指南。實際解剖、入口位置、術式與治療計畫應由合格醫療團隊依個別患者的症狀、檢查與影像判斷。

正式對外或臨床使用前，應由顳顎關節／口腔顎面外科醫師確認解剖、影像、術式與適應情況，並由衛教人員確認病人理解度。專案文件記錄的是可重現的設計決策與工作流程，不包含或取代任何個人化醫療判斷。
