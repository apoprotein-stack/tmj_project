# TMJ Patient Education Visuals

顳顎關節（TMJ）衛教圖片專案，包含主題一「認識顳顎關節與常見問題」及主題二「微創顳顎關節內視鏡手術的原理與適應症」的視覺素材。

## 內容

- `assets/theme1/`：顳顎關節位置、關節盤正常與移位、張口運動、常見問題、症狀來源。
- `assets/theme2/`：微創內視鏡原理、適應症與病理狀態、入口位置與概念流程。
- `assets/theme2/archive_original/`：主題二早期版本，保留作為設計修訂紀錄。
- `source/`：原始衛教簡報。

## 視覺標準

主題二採用「正常比例的外部解剖定位＋獨立的關節腔放大視窗」標準。放大視窗均明確標示 `ENLARGED — NOT TO SCALE` 或 `SCHEMATIC — NOT TO SCALE`，避免將衛教示意誤解為實際人體比例或手術操作圖。

## 醫療使用提醒

所有圖片皆為患者衛教示意圖，不能單獨作為診斷、適應症判定或手術操作指南。實際解剖、入口位置、術式與治療計畫應由合格醫療團隊依個別患者的症狀、檢查與影像判斷。
